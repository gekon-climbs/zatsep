# Зацеп — прогресс на скалодроме

PWA для Android: трассы, пирамида 1–2–4–8, звания, квесты, цели и ачивки. Работает без интернета, данные хранятся на телефоне.

## Файлы

- `index.html`, `styles.css` — разметка и стили
- `app.js` — экраны и действия
- `logic.js` — правила: очки, пирамида, звания, квесты, цели, ачивки
- `store.js` — хранение данных (IndexedDB), миграции, резервные копии
- `sw.js` — service worker: офлайн-режим и обновления
- `manifest.webmanifest`, `icons/` — установка на главный экран

## Как выложить

PWA ставится на телефон только с адреса `https://`. Адрес должен оставаться **одним и тем же навсегда**: данные привязаны к адресу сайта.

Вариант через GitHub Pages:
1. Создай репозиторий на github.com, загрузи в него содержимое папки `climb-app` (Add file → Upload files).
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
3. Через минуту сайт будет по адресу `https://<логин>.github.io/<репозиторий>/`.
4. Открой его в Chrome на телефоне → меню ⋮ → «Установить приложение».

## Как выпустить новую версию

1. Поменяй код.
2. Увеличь `VERSION` в `sw.js` и `APP_VERSION` в `app.js` (например, `1.0.0` → `1.1.0`). Без этого телефон не увидит обновление.
3. Если поменялась структура данных — увеличь `SCHEMA_VERSION` в `store.js` и добавь функцию в `MIGRATIONS`.
4. Загрузи файлы на тот же хостинг. В приложении появится кнопка «Обновить».

Данные тренировок лежат в IndexedDB и при обновлении не трогаются. Перед каждой миграцией формата приложение само сохраняет копию старых данных. Раз в месяц делай резервную копию: «Правила» → «Сохранить копию».

## Локальный запуск

```bash
python -m http.server 8765 --directory climb-app
```

Потом открой http://localhost:8765.
